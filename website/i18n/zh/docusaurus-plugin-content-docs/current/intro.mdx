# 从提交记录确定下一个版本

`flopha` 读取 Git 标签和提交消息，计算下一个语义化版本，并创建标签、更新日志和 GitHub Release。你可以在终端或 CI 中运行，也可以使用 [GitHub Action](https://github.com/sjquant/flopha/blob/main/docs/github-action.md)。

```console
$ git log --oneline v1.2.3..
3f2c1a9 fix: handle empty input
a1b2c3d feat: add release notes export

$ flopha next-version --auto
v1.3.0
```

## 适用场景 {/* #when-it-fits */}

flopha 通过 Git 标签或分支名管理版本，适合以下场景：

- 希望根据提交消息确定下一个版本，而不是手动选择版本号
- 希望用一条命令或一个工作流步骤创建标签、更新日志和 GitHub Release
- 使用 `desktop@1.4.2`、`release/1.4.2` 等自定义版本格式
- 在 `Cargo.toml`、`package.json`、`pyproject.toml` 中维护版本，并希望在创建标签前将新版本写入这些文件
