# バージョンパターン

`flopha` は、次の 3 つのプレースホルダーを含む文字列パターンでバージョンを検索・生成します。

- `{major}`
- `{minor}`
- `{patch}`

`{major}.{minor}.{patch}` は `{semver}` と省略できます。

## よく使う例 {/* #common-examples */}

```bash
flopha last-version --pattern "v{major}.{minor}.{patch}"
flopha next-version --pattern "desktop@{semver}"
flopha next-version --pattern "release/{major}.{minor}.{patch}" --source branch
```

## パターンの照合方法 {/* #how-matching-works */}

パターンは内部で文字列全体を照合する正規表現に変換されます。固定の文字列は完全に一致する必要があります。プレースホルダーは数字のキャプチャグループとして扱われます。

たとえば、次のように照合されます。

- `desktop@{major}.{minor}.{patch}` は `desktop@1.3.7` に一致します。
- `desktop@{semver}` は `desktop@1.3.7` に一致します。
- `release/{major}.{minor}.{patch}` は `release/2.0.0` に一致します。
- `v1.{minor}.{patch}` は操作対象を `1.x` 系列に限定します。

## タグの代わりにブランチを使う場合 {/* #when-to-use-branches-instead-of-tags */}

Git タグではなくリリースブランチでバージョンを表す場合は、`--source branch` を使ってください。

```bash
flopha next-version \
  --source branch \
  --pattern "release/{major}.{minor}.{patch}" \
  --create
```

## プレリリースのチャネル {/* #pre-release-channels */}

プレリリースのバージョンは、必ず計算した安定版のバージョンに接尾辞を付けて作成します。

```bash
flopha next-version --pre alpha
flopha next-version --pre beta
flopha next-version --pre rc
```

リポジトリに `v2.4.0-rc.1` がある場合、次の実行では `v2.4.0-rc.2` が生成されます。
