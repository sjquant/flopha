# Installation

## Install the binary

Prebuilt binaries are available for macOS (Intel, Apple silicon) and Linux x86_64:

```bash
curl -fsSL https://raw.githubusercontent.com/sjquant/flopha/main/scripts/install.sh | sh
```

The installer places the binary under `~/.flopha/bin` unless `FLOPHA_INSTALL` is already set. If `flopha` is not on your `PATH` afterwards, add this to your shell profile:

```bash
export FLOPHA_INSTALL="$HOME/.flopha"
export PATH="$FLOPHA_INSTALL/bin:$PATH"
```

## Build from source

On other platforms, or to track `main`, install with Cargo:

```bash
cargo install --git https://github.com/sjquant/flopha --locked
```

## Verify

```bash
flopha --version
```

Then follow the [Quick Start](/docs/quick-start).
